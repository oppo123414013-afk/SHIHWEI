# 客製化股票 Dashboard 製作流程

> 以 ONDS（Ondas Inc.）為範例，完整記錄從零到上線的每一步。

---

## 第一步：搜尋股票資料

對 Claude 說：

```
現在幫我用 股票樣板MD檔 做一個 【股票代碼】 股票分析的PDF檔給我
你要應對這家公司的資訊去改變內容
```

Claude 會自動執行以下搜尋：

```
【代碼】 stock price analysis 2026
【代碼】 financial results earnings 2026
【代碼】 stock technical analysis analyst rating May 2026
【公司名】 business news partnerships 2026
【代碼】 52 week high low insider trading
```

---

## 第二步：產出 PDF 分析報告

Claude 會：
1. 根據 `templates/股票樣板.md` 填入蒐集到的資料
2. 將 MD 存至 `C:\tmp\SHIHWEI\reports\【代碼】_【日期】_report.md`
3. 執行轉換指令：

```powershell
$env:NODE_PATH = "C:\Users\User\AppData\Roaming\npm\node_modules"
node "C:\tmp\SHIHWEI\reports\md_to_pdf.js" `
  "C:\tmp\SHIHWEI\reports\【代碼】_【日期】_report.md" `
  "C:\tmp\SHIHWEI\reports\【代碼】_【日期】_report.pdf"
```

---

## 第三步：製作 HTML Dashboard

對 Claude 說：

```
我是希望你可以做成這樣的版本
https://oppo123414013-afk.github.io/pgy-monitor/pagaya/pgy_live_dashboard.html
```

Claude 會：
1. 讀取 `pagaya/pgy_live_dashboard.html` 的 CSS / 設計語言
2. 複製相同設計框架，依公司特性調整：
   - **主題色**：依產業換色（國防橙、金融藍、生技紫…）
   - **徽章內容**：換成該公司最新亮點
   - **AI 三方觀點**：Gemini / ChatGPT / Grok 各自角色客製化
   - **特有區塊**：金融科技用 ABS；無人機用合約/積壓訂單；SaaS 用 ARR…
   - **Chart.js 圖表**：填入該公司歷史季度數據

---

## 第四步：轉成 Dashboard PDF（可選）

對 Claude 說：

```
可以幫我把剛剛 【代碼】 的 html 檔做成 PDF 給我嗎
```

Claude 執行：

```powershell
$env:NODE_PATH = "C:\Users\User\AppData\Roaming\npm\node_modules"
node "C:\tmp\SHIHWEI\reports\html_to_pdf.js" `
  "C:\...\pagaya\【代碼】_dashboard.html" `
  "C:\tmp\SHIHWEI\reports\【代碼】_Dashboard_【日期】.pdf"
```

---

## 第五步：建立資料夾 & 上線

對 Claude 說：

```
這份資料幫我存起來，建立一個客製化股票資料夾，然後裡面放進去新建的 【代碼】 網站
```

Claude 會：
1. 在 `custom-stocks/` 下建立 `【代碼小寫】/` 子目錄
2. 將 Dashboard HTML 存為 `custom-stocks/【代碼小寫】/index.html`
3. 更新 `custom-stocks/index.html` 加入新的股票卡片
4. 存記憶（供下次對話使用）
5. `git add + commit + push` → GitHub Pages 自動更新

---

## 第六步：確認 nav 返回按鈕（必做）

每支股票 Dashboard 的 `<nav>` 必須包含兩個返回連結：

```html
<nav class="nav">
  <a href="../../index.html" style="font-weight:700;color:var(--主色);margin-right:4px">← 分析中心</a>
  <a href="../" style="font-weight:700;color:var(--t);background:rgba(【主色RGB】,.15);border:1px solid rgba(【主色RGB】,.4);padding:3px 10px;border-radius:20px;font-size:12px;margin-right:8px">客製化股票</a>
  <!-- 其他 anchor 連結 -->
</nav>
```

**各股票主色 RGB 對照：**

| 股票 | 主色變數 | RGB 值 |
|------|---------|--------|
| ONDS | `--o` 橙 | `255,166,87` |
| FIG  | `--p` 紫 | `188,140,255` |
| UPST | `--bl` 藍 | `88,166,255` |
| IREN | `--o` 橙 | `255,166,87` |
| AXTI | `--g` 綠 | `63,185,80` |
| COHR | `--cy` 青 | `0,212,255` |
| UI   | `--y` 金 | `210,153,34` |

**規則：**
- `← 分析中心` 指向 `../../index.html`（網站根目錄首頁），用主色標示
- `客製化股票` 指向 `../`（`custom-stocks/index.html`），用膠囊樣式 + 主色半透明底色
- 兩個連結讓使用者可以從個股頁面返回任一層級
