# 客製化股票 Dashboard 製作流程

> 以 ONDS（Ondas Inc.）為範例，完整記錄從零到上線的每一步。

---

## 第一步：搜尋股票資料

對 Claude 說：

```

你要應對這家公司的資訊去改變內容
```

Claude 會自動執行以下搜尋：

```

【公司名】 business news partnerships 2026
【代碼】 52 week high low insider trading
```

## 第二步：產出 PDF 分析報告

Claude 會：
1. 根據 `templates/股票樣板.md` 填入蒐集到的資料
2. 將 MD 存至 `C:\tmp\SHIHWEI\reports\【代碼】_【日期】_report.md`
3. 執行轉換指令：


## 第三步：製作 HTML Dashboard

對 Claude 說：

```
我是希望你可以做成這樣的版本
https://oppo123414013-afk.github.io/pgy-monitor/pagaya/pgy_live_dashboard.html
```

Claude 會：
1. 讀取 `pagaya/pgy_live_dashboard.html` 的 CSS / 設計語言
2. 複製相同設計框架，依公司特性調整：
   - **主題色**：依產業換色（國防橙、金融藍、生技紫…）
   - **徽章內容**：換成該公司最新亮點
   - **AI 三方觀點**：Gemini / ChatGPT / Grok 各自角色客製化
   - **特有區塊**：金融科技用 ABS；無人機用合約/積壓訂單；SaaS 用 ARR…
   - **Chart.js 圖表**：填入該公司歷史季度數據

## 第六步：即時股價 + 走勢圖 + 漲跌分析（標準功能，必含）

每支股票 Dashboard 必須包含以下即時更新功能（與 PGY Dashboard 一致）：

### 6-1 Header 即時股價

Header 的股價和漲跌幅必須加上 id，讓 JavaScript 動態更新：

```html
<!-- 標籤改為 LIVE，不再寫死日期 -->
<div class="live-badge"><span class="ldot"></span>LIVE · Yahoo Finance</div>

<!-- 股價 id -->
<span id="hdr-price" style="font-size:40px;...">$XX.XX</span>

<!-- 漲跌幅 id -->
<span id="hdr-chg" style="...">▲ +X.XX%</span>

<!-- 狀態行 -->
<span id="mkt-status" style="font-size:12px;color:var(--m)">讀取中...</span>
<span id="hdr-upd" style="font-size:11px;color:var(--m)"></span>
```

### 6-2 即時走勢圖區塊（`#live`）

在核心指標卡片後、漲跌分析前插入：

```html
<div id="live" class="sec">
  <div class="sec-ttl">今日走勢 <span style="font-size:10px;...">Yahoo Finance · 自動更新</span></div>
  <div class="card" style="padding:20px">
    <div style="border-radius:8px;overflow:hidden;background:var(--s2);height:300px;position:relative">
      <canvas id="intradayChart" style="width:100%;height:100%"></canvas>
      <div id="intraday-loading" style="position:absolute;inset:0;display:flex;align-items:center;justify-content:center;color:var(--m);font-size:13px">⏳ 載入走勢中…</div>
    </div>
    <div id="intraday-info" style="margin-top:10px;font-size:11px;color:var(--m);display:flex;gap:20px;flex-wrap:wrap">
      <span>Yahoo Finance 1m · 自動更新</span>
    </div>
  </div>
</div>
```

### 6-3 漲跌分析區塊（`#why`）

在走勢圖後、AI 觀點前插入動態漲跌分析，必須加上以下 id：

```html
<div id="why" class="why">
  <div class="why-hd">
    📊 今日漲跌分析
    <span id="why-badge" class="why-badge" style="background:rgba(139,148,158,.2);color:var(--m)">連線中...</span>
  </div>
  <div id="why-body" class="why-body">正在連接 Yahoo Finance 取得即時資料...</div>
  <div class="why-foot">
    <div>前收：<span id="w-prev">─</span></div>
    <div>今日振幅：<span id="w-range">─</span></div>
    <div>量能：<span id="w-vol">─</span></div>
    <div>即時更新：<span id="w-time">─</span></div>
  </div>
</div>
```

### 6-4 Nav 連結

Nav 中必須包含 `#live` 和 `#why` 連結（在 `#news` 之前）：

```html
<a href="#live">📡 即時行情</a>
<a href="#why">📊 漲跌分析</a>
```

### 6-5 即時更新 JavaScript

在原有 Chart.js 圖表 `</script>` 之後，`</body>` 之前，加入以下 JS（修改 `TICKER` 和 `AVG_TARGET`）：


### 即時功能行為說明

- **開盤中（美東 9:30–16:00 週一至週五）**：每 60 秒自動重拉 Yahoo Finance 1m 資料
- **收盤後**：顯示當日收盤價與最終漲跌幅，不再自動刷新
- **資料失敗**：15 秒後若仍無資料，顯示 Yahoo Finance 連結備援
- **CORS 備援**：corsproxy.io → allorigins.win 雙 proxy，任一失敗自動切換

## 第八步：確認 nav 返回按鈕（必做）

每支股票 Dashboard 的 `<nav>` 必須包含以下返回連結：

```html
<nav class="nav">
  <a href="../" style="font-weight:700;color:var(--t);background:rgba(255,255,255,.1);border:1px solid rgba(255,255,255,.25);padding:5px 14px;border-radius:20px;font-size:13px;margin-right:12px">← 返回客製化股票</a>
  <!-- 其他 anchor 連結 -->
</nav>
```

**規則：**
- `← 返回客製化股票` 指向 `../`（`custom-stocks/index.html`）
- 樣式統一使用白色半透明（`rgba(255,255,255,.1)` 底色、`rgba(255,255,255,.25)` 邊框），不因股票顏色而改變
- 文字顏色固定用 `var(--t)`（白色），所有股票統一
