# 川普每日動態報告｜2026-05-30 08:00 台北時間

## 一、政治與政策動態

1. **國殤日演說（Memorial Day）｜2026-05-25**
   川普出席阿靈頓國家公墓國殤日典禮，紀念陣亡將士。演說中強調「沒有國殤日，就沒有獨立紀念日」，並特別提及在「Epic Fury行動」（美國對伊朗軍事行動）中陣亡的13名士兵。同時提到美國即將迎來建國250週年是「歷史性里程碑」。

2. **伊朗核談判接近尾聲｜2026-05-24**
   川普表示與伊朗協議的「最終條款將很快宣布」，但同時指示談判代表「不要急於達成協議」。據報導雙方已接近達成終止伊朗戰爭的協議，惟細節尚未公開。

3. **川習峰會後中美貿易趨穩｜2026-05-14**
   川習峰會建立在兩人去年在南韓會議達成的貿易戰緩和基礎上。川普將美中兩國稱為「G2」，峰會涵蓋中國農業與工業採購、關稅、台灣及稀土議題，市場預期貿易關係進一步穩定。

4. **川普個人股票交易披露｜2026-05-19**
   川普披露2026年高達3,711筆股票交易記錄，部分交易涉及其政策直接影響的公司，引發利益衝突爭議。其在大型科技股的布局帶來巨額獲利。副總統萬斯亦遭質疑同期密集交易。

5. **大法官裁決削弱關稅權力｜2026-02-20**
   美國最高法院以6比3裁定，總統無權依IEEPA（國際緊急經濟權力法）徵收關稅，此裁決使川普2025年大多數關稅措施失效，川普隨即轉以第122條款、第232條款等其他法律依據重新布局關稅政策。

## 二、關稅 / 貿易政策

- **全球基準關稅（第122條款）｜2026-02-20**
  最高法院裁決後，川普立即依第122條款對所有國家徵收10%全球基準關稅，以應對「美國巨額國際收支赤字」。川普一度宣布將提升至15%，目前仍維持10%。

- **鋼鐵、鋁、銅強化關稅｜2026-04-02**
  川普簽署公告，強化對進口鋼鐵、鋁及銅的第232條款關稅，理由為國家安全威脅。

- **醫藥品關稅（100%）｜2026-04-02**
  對具有專利保護的進口藥品及原料藥徵收100%關稅：大型製藥公司120天後生效，中小型公司180天後生效。

- **新301條款調查｜2026-03-11**
  美國貿易代表署（USTR）啟動多項新301條款調查，針對「製造業結構性產能過剩」，調查對象包含中國、歐盟、越南、台灣、日本、印度等主要貿易夥伴。

- **中美貿易戰現況**
  川習峰會後，雙方展現和解跡象；中國批評新關稅調查為「課徵關稅的藉口」，同時推出五年計畫強調科技自立與工業製造升級。

## 三、市場 / 經濟聲明

- **聯準會堅守利率不降｜2026-04-29**
  Fed在川普多次施壓下，維持基準利率於3.5%～3.75%不動。Fed主席鮑威爾持續抵制降息要求，但川普提名的兩位理事（Miran、Waller）已在會議上投票支持降息。

- **新Fed主席提名**
  川普提名前Fed理事Kevin Warsh接任鮑威爾，參議院銀行委員會已以黨派立場通過提名，預計全院跟進。伊朗戰爭導致油價飆升，成為降息主要障礙。

- **經濟數據喜憂參半**
  - 正面：S&P 500自2024年11月大選後總報酬近30%；2026年第一季企業設備投資成長逾10%；私人就業月增2.5倍高於2025年均值。
  - 負面：消費者信心降至歷史低點；4月PPI通膨達6%（2022年12月以來最高）；批發通膨多年來最高。

- **川普個人股票持倉**
  揭露在大型科技股大量布局並獲得豐厚報酬，外界質疑政策與個人投資之間的利益衝突。

## 四、地緣政治 / 外交動向

### 伊朗
- 2026年2月，川普與以色列聯手對伊朗發動重大軍事打擊（Operation Epic Fury），目標為政權更迭。
- 目前正與伊朗進行和談，川普稱協議「即將達成」，但指示談判代表「勿急於求成」。
- 13名美軍在此次行動中陣亡，川普於國殤日特別致哀。

### 台灣
- 川普暫停對台軍售，台灣正等待國會批准的140億美元軍售及積壓的297.2億美元軍備。
- 川普訪北京後暗示，保衛台灣民主已非首要優先，引發分析人士批評美國對台承諾動搖。

### 烏克蘭
- 美國主導穿梭外交，與烏克蘭及歐洲達成修訂版和平框架草案，涵蓋安全保障與經濟支持。
- 川普政府向烏克蘭施壓接受俄羅斯有利條款，並稱烏克蘭對戰爭「負有部分責任」，俄方領土訴求仍懸而未決。

### 中東 / 巴勒斯坦
- 川普持強力挺以立場，支持以色列在加薩的軍事行動，並提議接管加薩、強制遷移巴勒斯坦人至約旦、埃及等阿拉伯國家，並將其轉型為特別經濟區。

## 五、對整體股市的影響分析

- **短期影響（1-3 日）：**
  伊朗和談若有具體進展，油價將承壓回落，有助科技、消費板塊反彈；PPI 通膨高企與消費者信心低迷形成對沖壓力。整體市場可能震盪偏多，需觀察伊朗談判是否有具體公告。

- **中期影響（1-4 週）：**
  全球基準關稅維持10%使製造業成本壓力持續；Fed維持利率不降壓縮估值空間；若Kevin Warsh完成接任且傾向降息，市場將正面解讀。關稅落地逐步衝擊企業盈利預期，特別是高度依賴進口原料的產業。

- **主要受益板塊：**
  - 國防／軍工（伊朗戰爭持續）
  - 美國本土鋼鐵、鋁製造（第232條款關稅保護）
  - 大型科技（川普個人持倉、AI支出維持）
  - 金融科技（CFPB鬆綁、白宮金融科技行政命令）

- **主要受害板塊：**
  - 進口製藥（100%關稅壓力）
  - 零售商（進口成本轉嫁消費者）
  - 台灣相關供應鏈（地緣政治風險升溫）
  - 能源進口導向企業（伊朗戰爭油價波動）

- **風險提示：**
  - 伊朗談判破裂 → 油價飆升、市場急跌
  - 最高法院進一步限縮行政權力
  - 川普個人股票交易引發國會調查
  - 美中貿易談判倒退

## 六、對 Pagaya（PGY）的影響分析

- **川普政策與 PGY 的關聯性：**
  川普整體政策傾向去管制、寬鬆金融監管，對以AI驅動信貸網絡為核心業務的Pagaya（PGY）相對有利。尤其是川普簽署的金融科技行政命令（2026-05-19）明確要求聯準會重新考量對金融科技公司的進入壁壘，直接利多PGY的業務拓展空間。

- **監管環境變化（CFPB、金融科技政策）：**
  - CFPB已被川普行政命令勒令停止所有活動，大幅降低對消費金融業者的合規壓力。
  - 2026年5月19日白宮行政命令《將金融科技創新納入監管框架》，明確推動金融科技和數位資產提供商整合進傳統銀行與支付體系，是PGY潛在重要利多。
  - 法官暫停CFPB開放銀行規則，使銀行與金融科技的合作框架趨於保守，可能影響PGY的數據合作模式。

- **信貸市場受影響程度：**
  PPI通膨達6%、消費者信心歷史低點，顯示信貸違約風險可能上升；Fed維持高利率壓縮借款人可支配所得，可能拉高PGY網絡的逾期率。另一方面，若金融科技業能更快速接入銀行系統，可擴大PGY的合作行銀覆蓋範圍，帶動放貸量成長。

- **對 PGY 股價的潛在影響：中性偏多**
  - 監管鬆綁與金融科技行政命令為結構性利多；
  - 信貸品質惡化風險為結構性壓力；
  - 短期市場情緒隨整體風險偏好而定，若伊朗和談落定、油價下行，有助金融科技估值修復。

- **重點關注事項：**
  1. PGY 2026年Q1財報細節（SEC 8-K揭露中）
  2. 白宮金融科技行政命令後續配套法規
  3. CFPB是否完全廢止或轉型
  4. Fed領導權交接（Warsh接任）後的貨幣政策走向
  5. 美國消費信貸違約率月度數據
